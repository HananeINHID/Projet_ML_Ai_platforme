Atelier Pratique - Prédiction de la Performance des Étudiants

Dataset des étudiants

L'objectif de cette démonstration est de vous montrer comment entraîner un modèle Random Forest pour prédire le Performance Index des étudiants en fonction de différentes caractéristiques telles que le nombre d'heures d'étude, les scores précédents, les activités extra-scolaires, le sommeil et le nombre de sujets pratiques réalisés. Le modèle, déjà pré-entraîné et sauvegardé, sera utilisé pour effectuer des prédictions à partir des données saisies par l’utilisateur via le formulaire de l’application. Une fois que l’utilisateur clique sur le bouton "Tester le modèle", les valeurs sont envoyées au modèle, qui retourne le score prédit.
