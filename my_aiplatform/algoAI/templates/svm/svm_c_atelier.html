Atelier Pratique - SVM - classification (Météo)

Dataset Météo

Le dataset météo contient des enregistrements journaliers de conditions météorologiques, y compris des caractéristiques telles que la température, l'humidité, le vent, et la pluie. L'objectif est de prédire si le temps sera ensoleillé ou pluvieux en fonction de ces caractéristiques.

Les Support Vector Machines (SVM) sont particulièrement adaptés pour ce type de classification binaire, où nous cherchons à séparer deux classes distinctes (ensoleillé vs pluvieux) en utilisant un hyperplan optimal.

Dans cet atelier, nous allons explorer comment entraîner un modèle SVM sur ce dataset, évaluer ses performances, et visualiser les résultats.
