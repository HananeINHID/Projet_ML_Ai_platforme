Algorithme de Support Vector Machines (Classification)

Détails:

Les Support Vector Machines (SVM) sont des algorithmes d'apprentissage supervisé utilisés pour la classification et la régression.

fonctionnent en trouvant l'hyperplan qui maximise la marge entre les différentes classes dans un espace à plusieurs dimensions.

Les SVM sont particulièrement efficaces pour les problèmes de classification binaire et peuvent être adaptés pour gérer des classes multiples.

utilisent des noyaux (kernels) pour transformer les données non linéaires en un espace où une séparation linéaire est possible.

Caractéristiques:

  • Capacité à gérer des données non linéaires grâce aux fonctions noyaux.
  • Robustesse face aux données de haute dimension.
  • Utilisation efficace de la mémoire en se concentrant sur les vecteurs de support.
  • Peut être utilisé pour la classification binaire et multi-classes.
  • Possibilité de régularisation pour éviter le surapprentissage.
