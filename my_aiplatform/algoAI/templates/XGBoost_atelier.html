Atelier Pratique - Classification du meteo

Dataset de pluie

'objectif de cette démonstration est de vous montrer comment entraîner un modèle XGBoost pour classifier les données selon différentes caractéristiques. Le modèle, déjà pré-entraîné et sauvegardé, sera utilisé pour effectuer des prédictions à partir des données saisies par l’utilisateur via le formulaire de l’application. Une fois l’utilisateur clique sur le bouton "Tester le modèle", les valeurs sont envoyées au modèle, qui retourne la catégorie correspondante. Cette approche est similaire à celle d’autres projets de classification, comme le cas « Rain / No Rain », où le modèle prédit la pluie ou non selon les données météo fournies par l’utilisateur.
