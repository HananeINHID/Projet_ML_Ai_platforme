Algorithme Arbre de Décision (Regression)

Détails:

L'algorithme d'Arbre de Décision est un modèle d'apprentissage supervisé utilisé pour la régression et la classification. Dans ce cas, nous utilisons un Arbre de Décision pour la régression afin de prédire le Performance Index des étudiants basé sur diverses caractéristiques.

Le modèle divise les données en segments basés sur les caractéristiques d'entrée, créant une structure arborescente où chaque nœud représente une décision basée sur une caractéristique spécifique. Le but est de minimiser l'erreur de prédiction en segmentant les données de manière optimale.

Le dataset utilisé est le Student Performance Dataset, qui contient des informations sur les habitudes d'étude, le sommeil, et les activités des étudiants, ainsi que leur Performance Index.

Caractéristiques:

  • Heures d'étude quotidiennes
  • Notes académiques précédentes
  • Participation aux activités extra-scolaires
  • Heures de sommeil par nuit
  • Nombre d'examens blancs pratiqués
